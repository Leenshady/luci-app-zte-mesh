# 2026-11-05

## 批 18 · 终端数的替身：问、答、采集三段各补一段

第 17 批收尾时 PLAN 第 3 节写着"主机侧没有可做的了，剩下的都卡在上机窗口"。**这句被用户一条追问推翻了**：
组合 ②③ 的「终端数」那一格是空的，而它空着的原因不是"要上机才知道"，是**沙箱里那个原厂 agent 压根没有可答的数据源**——
原厂这一格数字来自无线驱动经 `cspd`，沙箱两样都没有，`ns-run` 建的私有根连 `/sys` 都不挂。
把缺的三段补上（宿主量数、沙箱应答、主控定时问）全是主机可测的，于是有了这一批。

### 先把前提测出来，再决定替身坐在哪

`tools/lab/enroller.c` 加了一个 `--metric`：按原厂 `I5TlvApMetricsQueryInsert` 的写法组一帧 AP Metric Query
（CMDU `0x800b`，TLV `0x93` = 计数 + BSSID 列表），发进沙箱，把回帧的 `0x94` 逐条打出来。读数很干脆——
**agent 收到查询，一声不响**。这一条决定了替身必须自己把答的那一半做出来，不是去修 daemon。
`--metric` 的注释里另留了两条依据：`0x93` 的字段形状（计数 + BSSID 列表）对着 MultiAP 规范 3.6 的 dissector 核过，
以及"查询点名一个这台 agent 不认识的 BSSID 时，原厂回 Error Code 而不是沉默"（`ApMetricsQueryReceive` →
`slave_find_bss` 那条路径的符号名）。**两条都还是推的，没在设备上读过**——正是 H-15 第⑦ 那半要读的，
别在这里写成已验。

三段各自的位置由"数在哪里"决定：

- **采集（A）在宿主**：`openwrt/zte-mesh/files/sta-collect`，procd 实例，5 秒一轮，写 `/run/zte-mesh/ap-sta`
  （一行 `epoch=`，之后每路一行 `BSSID 数`）。三个坑是它的判据：①**AP 名单只取 netifd 里 `mode=ap` 的接口**——
  子节点那条朝主控建的回程 sta 接口自己也有 `stations` 目录，把它数进去就等于"这台子路由有一个终端，就是主控"；
  ②**计数走 debugfs**（`/sys/kernel/debug/ieee80211/phy*/netdev:<if>/stations`），因为 ax3600 那种出厂镜像上
  `iw`、`hostapd_cli`、`wpa_cli` 一个都没有，目录列举不需要包也不需要守护进程在说话；
  ③**整表先写到临时名再 `mv`**——应答的那一侧正在读它，半份文件就是一份半网络。
  `stations` 目录**不存在**时这一路整个不进表：内核没话说≠"0 个终端"，一行 0 会被当成量过的数报回主控。
- **应答（B）在沙箱内**：`src/agent-ap-metrics.c`，编进 `libzte_controller_trace.so`，挂在收帧钩子上。
  空列表＝本机跑的每一路；点名的只回点名的那几路；表超过 30 秒没刷新、或 `epoch` 落在未来 ⇒ **回 0 字节＝不吭声**。
  30 秒是六个采集周期，也是主控给一个 `.sta` 文件的有效期——同一个数在链路上只该有一个新鲜度定义。
  发送用的是**查询到达的那个 socket**，而且绕开 `controller-trace.c` 自己的 `sendto` 包装直接 `dlsym(RTLD_NEXT)`：
  走包装等于替 daemon 伪记一次它没做过的收发，日志会说谎。
- **问（C）在主控**：`ap_metrics_query_build()` 组空列表查询，`controller_ap_metrics_query()` 从 `veth-lab`
  （daemon 真正在用的那个口）发出，源地址取 `br0` 的 AL MAC，**发出即不读应答**——应答按那个 MAC 回到 daemon
  自己的 socket，`controller-trace.c` 照常交给 `controller-peer.c` 落盘。**这是这一批最值得留着的一个形状**：
  原厂子节点（真驱动）与 OpenWrt 子节点（这张表）在主控这一侧是同一条写入路径，主控不需要分两条路读，
  也没有为替身新增第二种状态。服务侧 `ap_metrics_reconcile()` 从拓扑就绪等 15 秒起、每 10 秒问**一个**节点
  （一次调用最多发一条，写 `state.json` 的那一秒循环不能被它拖住），节点离开拓扑就停问，文件自己过期——
  这是"这台的终端数还没人上报"和"这台不在了"的分别。

被否掉的一条：主控替子节点猜数。缺的那一路**不补 0**、整表过期**不答**，宁可为空。

### 测到什么

新增 `tests/agent-ap-metrics-codec` **85 条断言 + 2 万条有界变异**，其中一条是整链的：用主控那侧的
`ap_metrics_query_build()` 组帧，喂给应答，再把回帧交给 `controller-peer.c`，看它按 BSSID 写出三个文件——
这条把"问的形状"和"答的形状"钉在一起，任一边单独改都会红。`controller-1905-codec` 212 → **261 条**
（`query_build_tests`：整帧 60 字节、type `0x800b`、末片非转发、`0x93` 长度 1 且计数 0、EOM、尾部补零、
id 0 合法、59 字节缓冲区与 NULL 都拒）；`tests/test_sta_collect.sh` **22 条**（桩住 `ubus`/`jsonfilter`/`date`，
所以判的是"哪个接口算 AP、哪个目录算终端"这件事本身）；`test_init.sh` 130 → **135**（子角色起 `sta-collect`、
主控不起、`stop_service` 删 `ap-sta`）；`test_runtime.py` 29 → **31**（包里的 trace `.so` 认不认得这条新帧路、
probe 带不带 `ap_metric_query` 那个 marker）。`controller-packet-codec` 162 条不变（发送侧要 raw socket，编得动、主机跑不了）。

### 两条只有这一批才撞得上的

**`make test-host` 根本不编 `controller-service.c`**。那处 `char *` 与 `unsigned char *` 的实参不匹配（`sscanf`
只吃 `unsigned int*`，而 MAC 是 `uint8_t[6]`）在本机与构建机的 `test-host` 里都不会响——它是 ARM32 的
`database` 目标（`out/db-engine-probe`）才编的一个文件。把 `-Wall -Wextra -Werror` 跑满不等于把改动编到：
**动了服务这一侧，必须单独跑 `sh tools/lab/build.sh database`。**

**`make -k` 不会把同一条 recipe 剩下的命令跑完**。构建机上 `test_schema` 因为缺 `out/analysis/cspd` 红 4 条
（那是环境事实，LAB 第 3 节记着），`-k` 只是让它依赖的**别的目标**继续，`test-host` 这条 recipe 里排在后面的
init、wlan-sync、`sta-collect`、装机验收、preload、沙箱**一个都没跑**。所以这一批的门是逐条单独跑的，
结果全绿：init 135／rpcd 24／wlan-sync 182／sta-collect 22／装机验收 224／i18n 12 过／runtime 0 failure／
frames 过／preload 5 场景／sandbox 15 过，C 侧 331／87／162／261／180873／162／239／20／85；
`test_luci.js` 用便携 `node.exe` 跑（构建机上没有 `node`，那条命令在 `make` 里本来就是跳过）：
`38 main options, 10 slot, 4 ACL, 2 client, child form 7`。缺 `cspd` 那四组仍是 4／5／6／1 条错（`test_schema`／`test_policies`／`test_profiles`／`test_startup`），与第 15 批那轮的读数一致。

**包与源码逐字节对上了**：构建机现编 `database` 之后 `warning`/`error` 各 0、`arm-linux-gnueabi-nm -u` 无
`__time64`/`__isoc23_`，三个成员与工作树里那份 `zte-mesh-runtime.tar.gz` 的哈希逐一相同——
`root/bin/db-engine-probe` `4465be7b…`、`root/lib/libzte_controller_trace.so` `78db13d8…`、`enroller.c` `05fb1c5a…`。
比对用 `tarfile` 逐成员读字节，不解包（LAB 第 3.0 节那条坑：归档里 `root/var/*` 是指向 `/tmp` 的符号链接，
Windows 上解不出来就会拷出一整份本机临时目录）。
